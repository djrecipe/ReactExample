# React Example
Simple demonstration using React.js in a modern ASP.NET with Aspire orchestration. The default project templates provided by Visual Studio do not include a fully working client/server implementation.

## Build Instructions
1. Install node.js from https://nodejs.org/en/download/
2. Run `npm i ./ReactExample.React/`
3. Build all

## Additional Information
A lot of this know-how was pulled from https://learn.microsoft.com/en-us/dotnet/aspire/get-started/build-aspire-apps-with-nodejs
